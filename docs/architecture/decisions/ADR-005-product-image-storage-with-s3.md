# ADR-005: 상품 이미지 원본 저장소로 AWS S3 사용

- 상태: 승인
- 적용 영역: backend
- 결정일: 2026-09-10

## 결정

상품 이미지 원본은 비공개 AWS S3 버킷에 저장한다. 클라이언트는 백엔드 이미지 등록 API에 파일을 전송하고, 백엔드가 파일을 검증한 뒤 S3에 업로드한다. PostgreSQL에는 객체 키와 상품 연결, 크기, 형식, 표시 순서 및 대표 여부를 저장한다. 전체 접근 URL과 만료되는 서명 URL은 영속화하지 않는다.

S3 업로드는 장시간 DB 트랜잭션 밖에서 수행한다. 업로드 후 이미지 메타데이터 저장과 상품 상태 전환을 하나의 짧은 DB 트랜잭션으로 처리한다. 확정된 등록 실패에는 해당 요청의 객체를 보상 삭제하고, 커밋 결과가 불명확하면 DB 참조를 확인하기 전에 삭제하지 않는다.

S3 연동은 상품 영역의 저장소 인터페이스와 infrastructure 구현으로 분리한다. IAM 권한과 환경 설정으로 접근하며 credential을 소스에 기록하지 않는다. CloudFront 도입, 다운로드 URL 발급과 다른 도메인의 저장소 공통화는 이 결정에 포함하지 않는다.

## 이유

상품 이미지 원본을 애플리케이션 서버의 로컬 파일과 분리해 관리한다. 백엔드 경유 업로드로 파일 검증과 등록 결과 처리를 한 유스케이스에서 조율할 수 있다. 객체 키 중심의 메타데이터는 이후 이미지 제공 방식을 결정할 때 등록 계약의 변경을 줄인다.

## 트레이드오프

클라이언트의 S3 직접 업로드와 비교해 백엔드가 파일 전송량과 검증 자원을 부담한다. S3와 DB에 걸친 원자적 트랜잭션은 없으므로 보상 삭제와 고아 객체 운영 정리가 필요하다. 로컬 파일 저장과 비교해 AWS 권한·설정과 외부 서비스 장애 대응이 필요하다. 비공개 원본을 브라우저에 제공하려면 이후 별도 접근 방식이 필요하다.
