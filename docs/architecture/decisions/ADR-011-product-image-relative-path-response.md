# ADR-011: 상품 이미지 조회 정보로 상대 경로 반환

- 상태: 승인
- 적용 영역: backend
- 결정일: 2026-09-10

## 결정

구매자 판매 상품 목록 API는 대표 이미지의 완전한 URL이나 S3 객체 키 필드 대신 `/products/{productId}/{requestId}/{objectId}` 형태의 `representativeImagePath`를 반환한다. 이 값은 저장된 객체 키 앞에 `/`를 붙여 만든다.

백엔드는 이미지 조회 응답에서 S3 Presigned URL을 생성하거나 이미지 제공 도메인을 결합하지 않는다. 프런트엔드가 환경별 이미지 기준 URL과 상대 경로를 결합한다. DB에는 기존과 같이 객체 키만 저장한다.

CloudFront, 비공개 S3 origin의 OAC, 캐시·서명 정책과 프런트엔드 기준 URL 설정은 후속 작업으로 구현한다. CloudFront 도입 이후에도 API 상대 경로 계약은 유지한다.

## 이유

이미지 객체는 비공개 S3에 있지만 현재 목록 조회에 만료되는 서명 URL이나 요청별 AWS 호출은 필요하지 않다. 상대 경로는 환경별 이미지 제공 도메인을 API 계약과 분리하며, 이후 CloudFront를 도입할 때 백엔드 응답과 DB 데이터를 변경하지 않게 한다.

필드명을 `representativeImagePath`로 명시해 완전한 URL로 오해하지 않게 하고 대표 이미지 하나만 제공해 목록 응답 크기를 제한한다.

## 트레이드오프

클라이언트는 이미지 기준 URL을 별도로 설정하고 상대 경로와 안전하게 결합해야 한다. CloudFront가 준비되기 전에는 이 경로만으로 이미지를 다운로드할 수 없으며, 이미지 표시 기능은 후속 작업에 의존한다.

상대 경로가 현재 객체 키 구조에 대응하므로 객체 키 경로 정책을 바꿀 때 기존 경로 호환성을 고려해야 한다. 향후 비공개 콘텐츠에 사용자별 접근 제어가 필요해지면 CloudFront signed URL 또는 signed cookie 등 별도 접근 정책을 설계해야 한다.
