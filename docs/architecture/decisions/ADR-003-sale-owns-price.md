# ADR-003: 판매 가격을 Sale이 소유

- 상태: 승인
- 적용 영역: backend
- 결정일: 2026-09-09

## 결정

`Product`는 상품명과 설명 같은 카탈로그 기본 정보를 관리하고 가격을 보유하지 않는다. `Sale`은 상품에 대한 실제 판매 조건인 가격, 판매 수량과 판매 시작·종료 시각을 관리한다.

판매자는 판매 일정을 등록할 때 1원 이상의 `Long`인 KRW 정수 가격을 필수로 입력한다. 같은 상품은 판매 일정마다 다른 가격을 가질 수 있다. 주문이 생성되면 구매 대상 `Sale`의 가격을 주문 상품에 스냅샷으로 저장한다.

## 이유

판매자에게는 판매 일정별 가격, 수량과 기간을 한 흐름에서 설정하는 방식이 자연스럽다. 상품의 카탈로그 정보와 판매 조건을 분리하면 기존 상품을 다른 조건과 가격으로 다시 판매할 수 있으며, 상품 정보 수정과 판매 조건 변경도 서로 독립적으로 관리할 수 있다.

## 트레이드오프

판매 일정이 없는 상품에는 표시할 가격이 없다. 상품 목록과 상세 조회는 노출 대상 판매 일정의 가격을 함께 조회해야 하며, 대표 가격이나 기본 가격이 필요해지면 별도 조회 규칙을 결정해야 한다.

`Product`와 `Sale`에 가격을 중복 저장하지 않으므로 가격의 단일 출처는 명확하지만, 판매 일정 생성 시에는 가격을 반드시 입력해야 한다. 주문 이후 가격이 변경되더라도 주문 당시 금액을 유지하기 위해 주문 상품에 가격 스냅샷을 별도로 저장한다.
