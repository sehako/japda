# ADR-034: 체크아웃 단일 쿼리 조회 모델 복원

- 상태: 승인
- 적용 영역: backend
- 결정일: 2026-09-20

## 결정

`GET /api/checkout`은 `CheckoutQueryRepository`의 단일 조회 계약을 사용한다. PostgreSQL 구현은 판매, 상품, 대표 이미지, 구매자의 배송지 book과 배송지를 한 번의 읽기 쿼리로 결합하고, application은 조회 행을 예상 총액과 HTTP 응답으로 조립한다.

Redis 캐시를 사용하지 않으며 상품 스냅샷과 배송지 조회 계약을 분리하지 않는다.

이 결정은 ADR-033을 대체하고 ADR-018의 단일 조회 모델을 다시 적용한다.

## 이유

체크아웃 화면에 필요한 상품 표시 정보와 구매자 배송지를 단일 조회로 가져와 데이터베이스 왕복을 줄인다. 캐시 제거 후에도 기존 단일 조회 동작과 HTTP 응답·오류 계약을 보존한다.

## 트레이드오프

조회 쿼리는 판매, 상품, 이미지와 배송지 테이블 구조에 함께 의존한다. 각 데이터를 독립적으로 조회하는 방식보다 쿼리 변경의 영향 범위가 넓지만, 체크아웃에 필요한 읽기 정보를 한 번의 PostgreSQL 조회로 얻는다.
