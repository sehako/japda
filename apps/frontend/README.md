# 프론트엔드

React + TypeScript + Vite 기본 스캐폴드에 TailwindCSS Vite 플러그인을 연결했다.

## 실행

`apps/frontend`에서 실행한다.

```bash
npm install
npm run dev
```

## 검증

```bash
npm run build
npm run lint
```

`build`는 TypeScript 검사 후 `dist`에 빌드 결과를 생성한다. `lint`는 기본 템플릿의 Oxlint 설정을 사용한다. `npm run preview`로 빌드 결과를 확인할 수 있다.
